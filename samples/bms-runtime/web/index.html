Output preferences apply to live play and replay. Custom latency accepts 0–60000 ms; leave the rate blank for automatic selection. The browser chooses supported settings. Latency is a hint, not a guaranteed buffer size; playback uses the actual opened rate.

Advanced audio capacities

Applies to live play and replay. These are application capacity limits; the browser chooses the callback size. Playback stops with an error if a chart or callback exceeds a limit. The command queue must also hold music prepared before playback starts.

Live play uses these original song positions with a short preroll. Leave the end blank to play through the song. Earlier notes and holds already in progress are excluded; overlapping music resumes from its original sound. Replay uses its recorded section.

Live judge windows are nonnegative; input offset may be signed. Use up to six decimal places. Replay uses its recorded judge. Saved opponents and multiplayer require compatible timing settings.

Keyboard bindings

Choose physical key positions for each lane. Unbound lanes must be absent from the prepared chart; one key can belong to only one lane. These page-local settings affect live play. Replay uses recorded inputs, and Escape always stops playback. Browser or system shortcuts may prevent some keys from reaching the game.
