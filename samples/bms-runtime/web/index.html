Keyboard bindings

Choose physical key positions for each lane. Unbound lanes need matching HID or Gamepad button bindings or must be absent from the chart; one key can belong to only one lane. These page-local settings affect live play. Replay uses recorded inputs, and Escape always stops playback. Browser or system shortcuts may prevent some keys from reaching the game.

Local players

One player uses inputs automatically. No source selection is needed.

For two to 64 players, discover inputs and assign a distinct acquired source to each player. Keyboard and touch each count as one source. HID and Gamepad profiles must cover each assigned player's chart lanes. Four players appear per page; held touches retain their lanes across page changes, and new contacts are unbound while their player is offscreen. Assign saved opponents to their comparison player in the selected list. Sources are released after play; discover again for another local session.

Hosts need the same chart, seed and output setup, and a compatible WebTransport server. Rooms use an HTTPS address ending in /rooms/key (letters, digits, - or _). The first host seals the roster after at least two hosts join, then every host selects Ready. The lobby waits up to 60 seconds. Rooms share a software start, reported scores, final acknowledgements and coordinated drain. The canvas shows four remote players per score page, identified by host and player; reported scores are not ranked results. Replay stays local.
