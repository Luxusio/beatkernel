# Policy-aware native saved ghosts

Nondefault native gauges can prepare saved own/other opponents with the exact
resolved gauge and judge setup. Canonical capture metadata includes finite
endpoints, and saved files must match before every operation is reconstructed
through section-aware replay. The same preparation serves solo and local member
owners, retaining original IDs. Builtin preparation keeps its prior identity
behavior. CLI/settings admit custom ghosts but still reject custom multiplayer
before networking. Generic score accounting is unchanged; no weighted/class
scoring or full historical timing compatibility is implied.

Verification: the full library passed 1,629 tests with two ignored; all executable
test suites passed 359 tests. The four saved-ghost fixture groups independently
passed. Workspace/all-target and WASM/browser checks passed, as did Windows GNU
and macOS Rust source checks with C stubs. Those cross-checks do not establish
native ABI, device or driver acceptance. Actual Linux help succeeded; all six
custom gauges with own/other ghost arguments passed policy admission and reached
the expected missing-recording error, while invalid/duplicate gauge and custom
network arguments refused. Independent DEEP code, security and documentation
reviews passed, followed by independent scoped CLI QA. The actual retained
settings screen showed `hard` and the complete shortened hint at 1280x960, then
closed successfully. Logs and screenshot are local ignored artifacts under
`target/wf/policy-ghost-final-qa-cli-*`.

## Known ceiling

Physical native acceptance and the full Goal remain unfinished. Custom
multiplayer, class-weighted scoring and historical timing/mine/empty compatibility
remain separate work. The host has no physical input device nodes, Windows/macOS
runtime or real ASIO SDK/MSVC acceptance environment.
