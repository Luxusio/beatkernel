# Worker-owned retained browser room Results

Browser room Results retains one immutable portable score archive after the
actual room owner finishes drain/close. Gameplay and audio ownership are released
through their existing paths; no callback or result page calls a freed gameplay
binding. Original prepared host/player order, accepted prefixes, finality,
missing scores and error/cancellation evidence remain distinct from ranked
authority. The archive uses the same model as native Results.

The Worker owns the Results binding and draws only its cached selected page on
the existing OffscreenCanvas renderer. Window keeps bounded page metadata and
previous/next controls through correlated requests, without receiving periodic
score arrays or drawing a gameplay DOM HUD. Paging never reopens Seal, Ready,
Leave or networking. New play/import/preview and Worker terminal failure release
the previous archive and fence its page replies. Display failure leaves joined
cleanup and replay outcome intact.

Independent deferred fixture source adds six groups: two portable builder groups,
two actual play-Worker groups and two actual Window host groups. The play-Worker
source now has 95 groups and the play-host source 97. They cover bounded word
decoding and freeze/page semantics, actual Owner drain/join with late accepted
prefixes after game.free, binding/page/discard ownership, metadata correlation,
replacement fencing and presentation-only failure. One prior stopped-HUD
expectation now checks the deliberate retained Results behavior; the earlier
groups remain. No fixture has been executed.

Both source writers actually stopped before scoped Rust formatting and
whitespace inspection. Workspace/all-targets with WebTransport (session 67067),
native no-default/all-targets with WebTransport (37773), WASM browser (41789) and
WASM browser-audio (46984) each exited 0. WASM retained three existing cadence
dead-code warnings. These are Rust compile-only checks and do not parse or run
the modified JavaScript. No tests, JavaScript parsers, applications, generated
bindings, browser/device/network execution, formal reviews, QA or close are run
in this implementation phase.

## Known ceiling

Actual browser/generated bindings, native GUI/device/TLS and measured performance
acceptance remain unverified. The full player Goal and Harness task remain open;
compile-only evidence cannot establish runtime PASS or ranked results.
The existing cleanup-failure policy may terminate the Worker and require reload;
retained paging does not bypass that fence. Only a surviving joined presentation
owner can browse its archive.
