# Seeded SWITCH chart branches

SWITCH/SETSWITCH, CASE, DEF, SKIP and ENDSW extend the existing preparation-only conditional parser. SWITCH draws from the same specified source-seed stream as RANDOM; SETSWITCH selects a constant without consuming a draw. Selected cases fall through subsequent cases/default until active SKIP or ENDSW. Inactive SKIP does not suppress a later matching case. Payload before the first selected case is discarded.

All ancestor activation gates remain effective after a nested SKIP. IF/ELSE or RANDOM scope endings cannot resurrect a skipped enclosing switch. Nested control syntax and original physical caps are still checked in discarded branches. CASE/DEF/ENDSW require the current switch scope; active SKIP targets the nearest labeled switch while retaining structured nested validation. ENDSW is mandatory, including at EOF. The common nesting cap remains 128; RANDOM-only EOF compatibility remains unchanged.

An optional single DEF is final; CASE after DEF rejects. Repeated/unordered CASE labels before DEF are accepted. This is an explicit bounded dialect, not a claim to reproduce every historical permissive player. The public seed APIs, replay metadata, live settings and shared judging/PCM runtime are unchanged.

Seven parser fixture groups cover fixed seed vectors, shared RANDOM/SWITCH draws, fallthrough, repeated/unordered labels, inactive/nested SKIP, ancestor masking, strict controls, EOF, physical/depth limits, original diagnostic lines, timing and duplicate policy. A composed preparation fixture selects CASE1 then CASE2, ignores missing skipped assets, verifies the selected key+BGM PCM against literal `[0.75, -0.375, 0.0]` values through the ordinary runtime/mixer, and round-trips the recorded seed through the replay codec and replay-aware asset loading. It also rejects the incompatible default branch. These fixtures are authored for later execution.
