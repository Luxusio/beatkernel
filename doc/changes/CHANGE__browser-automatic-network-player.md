# Automatic one-player network cohort

All live Page network sessions use the same group path. A sole player receives
one actual stable member ID and an automatic Any-source plan without device
selection. Every genuinely admitted keyboard, touch, HID and Gamepad source
retains the original solo eligibility and provenance. Untargeted saved opponents
are assigned internally to that member without modifying the user's selections.
Preparation, replay budgets/captures and final saved/peer results use the actual
one-member cohort schema; non-network solo and replay retain their prior paths.

Six deferred test groups were added: the local host helper has one new group
(five total), and the actual Page fixture has five (87 total). Existing Page
network cases now use explicit Any-cohort preparation, captures and peer results.
The new cases cover mixed input provenance, automatic/custom source eligibility,
immutable saved targets, complete member export/save and refused preparation or
error-prefix retry. No parser, assertion or browser runtime was executed, and
no Cargo checks were repeated for this JS-only change.

Known ceiling: Native application network callers still use scalar mode and
need group integration to connect to the Page's group mode. Lower-level scalar
Session APIs remain available but cannot negotiate with group Sessions.
Multi-host rooms, actual generated bindings/browser/device/audio/transports,
measured performance and formal review/QA acceptance remain unfinished.
Fixtures are authored for later execution under the standing deferral; source
changes do not establish full player completion.
