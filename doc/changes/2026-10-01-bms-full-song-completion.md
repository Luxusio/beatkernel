# Native full-song completion

Windows, Linux and macOS live BMS play now default to the whole song, with
optional `--seconds` retaining a bounded diagnostic cutoff. A portable prepared
completion component checks terminal judge state, retired BGM, a later idle
mixer block and actual output-domain native presentation before cleanup and
results. It preserves the last keysound/BGM tails instead of stopping at the
last note or an arbitrary duration. Checked wide arithmetic derives Windows
initial calibration bounds from actual chart/PCM data without a one-hour song
limit. Known ceiling: completion depends on reliable native presentation
observations and the existing full-queue render admission behavior; verify
these boundaries during deferred native acceptance. Fixtures are authored and
compiled only; tests, actual native output, independent review and QA remain
deferred. The full player objective remains unfinished.
