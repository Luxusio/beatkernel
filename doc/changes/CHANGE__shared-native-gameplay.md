# Shared native solo gameplay

Linux ALSA/evdev, macOS CoreAudio/IOHID and Windows WASAPI/Raw Input previously repeated solo gameplay sequencing. All three entry points now call `native_gameplay::run_gameplay` with generic native device adapters. The shared owner coordinates native pause acknowledgements, original input admission, bounded backlog, judgment, replay capture, competition publication, BGM feeding, presentation discipline and finite/full completion. Native stop/join, registration cleanup and saving the captured prefix remain with each resource owner.

Input acquisition continues while acknowledgements are pending; the shared FIFO has an explicit 65,536-event ceiling. Native acquisition is bounded to 256 items per pass. Resume reconciliation precedes post-resume input and waits for the native backlog to drain. The same checked 0–1 second advance lag applies to all three platforms, including the formerly unused Windows setting.

Windows resume reseeds presentation discipline from the original accepted WASAPI snapshot. Supplied normalized pairs are not mixed into an observer that subsequently consumes raw native counters. Physical stream origin, selected playback origin and logical song origin remain distinct. ASIO retains its bounded native end evidence and backend scheduling capability.

The inline fake-device fixtures use the actual runtime/mixer/capture components and are prepared for later execution. This slice permits compilation only. Native hardware timing, driver behavior, desktop rendering, multiplayer execution, formal review and QA are deferred; compilation is not runtime acceptance. Local-cohort gameplay/setup/discovery and ASIO bounded-interval startup remain subsequent work.

After every writer stopped, the first five compile checks exposed two incorrect import paths in the new common module. The imports and a fixture borrow were corrected, then all five configurations passed `cargo check` (exit 0): workspace/all targets, Windows GNU/all targets, macOS/all targets, no-default-features/all targets, and WASM library with graphics/no default features. Dedicated final artifacts are `target/ac140-{host,windows,macos,headless,wasm}-2.exit`. Scoped formatting and `git diff --check` also passed. Existing WASM cadence dead-code warnings and the macOS dependency future-compatibility warning remain. ASIO SDK compilation and all fixture/native execution are deferred.
