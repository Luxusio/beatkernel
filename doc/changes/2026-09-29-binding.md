# Phase 3 binding

`beatkernel::input` now maps complete physical identities and device selectors to caller-defined game controls. Exact rules override common fallback for the same source/control, fanout follows insertion order, and duplicate edits are atomic. Owned logical outputs retain typed button/axis/touch/pointer/pose samples and all clock/native provenance; raw/custom bytes require adapter interpretation first. Public-contract tests exercise selection, editing, namespace separation, unusual floating-point bits, output lifetimes, and virtual FIFO integration. A virtual example demonstrates two same-key keyboards and a touch channel, and its command is included in CI and Harness verification. Native input and all remaining ordered phases remain required.
