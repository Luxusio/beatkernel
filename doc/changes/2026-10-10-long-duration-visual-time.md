# Long-duration visual time

Kernel lane projection now measures local scroll displacement directly, avoiding
loss of ordinary note motion after a large accumulated scroll history. Crossed
markers use a compact setup-time range index rather than a frame-time scan.
Independent fixtures cover true twenty-hour/week extents, integer Runtime/judge
and replay identity, local geometry and retained app note-input epochs. See the
[precision contract](../kernel/REQ__long-duration-visual-time.md) for exact
reproduction and verification evidence.

## Known ceiling

Bounded virtual schedules and CPU renderer-input fixtures do not prove a
physical weeklong soak, actual GPU output, native audio latency or world-leading
performance. Approximate visual arithmetic within a queried range remains
separate from exact integer judge time. Full player WBS acceptance remains open.
