One immutable common setup owns the judge windows and resolved gauge profile.
The exact selection parser names the builtin policy and six existing adapter
variants. Explicit BMS hit classes determine opaque-grade deltas; TOTAL/stage
resolution retains fallback provenance and no historical timing table is
invented. Invalid grade/class/window setups refuse before gameplay. Existing
native profile preparation uses the common builtin constructor with unchanged
window/offset/default-gauge behavior. Parts transfer by ownership into existing
runtime/capture components; no native IO, dynamic dispatch or new crate is added.
Independent code and security review passed after correcting the adapter method
and preserving the original native boxed JudgeError/display boundary. Scoped
documentation review passed in an existing read-only review lane because the
runtime refused a fresh documentation thread; this is non-attesting for a
full-task documentation identity. Independent QA passed 1,607 library tests
(2 ignored) and 242 application tests with no failures. The four new fixtures
include actual Runtime/capture/replay behavior across all six kinds, invalid
setups and native error compatibility. Workspace all-targets, browser WASM and
normal Windows/macOS all-targets source checks each exited 0. Cross checks used
C stubs and do not establish SDK/HAL/device execution.

Public CLI/UI selection and nondefault live native admission remain unfinished,
as do class-aware score labels and full mine/empty semantics. Native finite
natural-completion acceptance still requires actual played-frame evidence on
an appropriate device; the previous null-device blocker is not erased.
