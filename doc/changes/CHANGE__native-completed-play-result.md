# Native completed live result publication

Actual solo/cohort pumps now return optional typed results only after the existing
finite/unlimited output-completion guards, using original scope and each owner's
gauge. Cancellation is rechecked before classification/marking/publication;
closure and diagnostic cutoff return no result. Old unit-returning calls wrap
the same implementation. No events are re-observed and no output evidence is
relaxed. Native compatibility entry points expose headless result values too.

Business hosts receive completed solo/whole-roster callbacks with default no-op
behavior. The compatibility host adapts these to player publication. Publication
refusal preserves the exact immutable result/table and original cause in typed
errors. PlayerSnapshot retains one complete result table after validating unique
registered identities, full coverage, common scope and gauge agreement. Tables
normalize to registered order; exact repeats do not republish and changed first
tables cannot replace historical completion. LocalPlayerSnapshot is unchanged.
First completion forces one nonblocking snapshot handoff attempt before cleanup;
cleanup failure preserves historical results with its separate Failed status.

Ten independent deferred fixture groups cover actual solo/cohort Mixer barriers,
fatal inputs, healthy/all-failed cohorts, scope, cancellation/cutoff/closure/errors,
publication error evidence, whole-roster atomicity and historical cleanup failure.
Cleared classification uses an injected known previous 60-hit gauge prefix; a
real 60-note input trace and OOM injection are not covered. After both writers
stopped, scoped rustfmt and git diff --check completed. All four root compile-only
checks exited zero: workspace/all-targets with webtransport; runtime/all-targets
without defaults with webtransport; WASM browser library; WASM browser-audio
library. Existing dead-code warnings remain; the prior test-only ClockPair
import warning was removed within the owned source path. Assertions, formal
review/QA, device/browser tests and benchmarks remain unexecuted; compilation
is not assertion success.
