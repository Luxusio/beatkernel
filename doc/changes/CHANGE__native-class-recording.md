# Native selected class recording

Shared native selected-policy capture preserves explicit hit classes together
with judge, gauge and original section metadata. Solo and local saved comparisons
prepare the identical policy header. Cold admission validates class coverage and
canonical metadata before common pump operations; the saved-record draft retains classes.
Builtin and explicit legacy helpers preserve their bytes. Unclassified custom
records refuse comparison against a new classified selection instead of being
assigned guessed EX meaning. All three OS launchers use these common helpers.
Verification: the full default/WebTransport library passed 1,646 tests with two
ignored; independent headless/WebTransport library QA passed 1,446. Explicit
desktop/WebTransport binary suites passed 367, with defaults-enabled workspace,
supplemental workspace/WebTransport all-target and WASM/browser source checks
passing. Code, security, scoped CLI QA and documentation reviews passed.
Actual Linux CLI cold admission accepted a Runtime-generated classified ghost
through compatibility and stopped at deliberately missing evdev acquisition;
legacy and equal-gauge/different-class ghosts refused compatibility earlier.
This did not open ALSA or execute physical gameplay. Logs are local ignored
artifacts under `target/wf/native-class-recording-*`.

Binary regression commands must include `desktop,webtransport` without disabling
default features. The headless all-bin tier passed 231 but omitted 136 main
desktop tests, despite reporting zero filtered tests. Retain feature coverage
explicitly rather than treating those two tiers as equivalent.
