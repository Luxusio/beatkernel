# Retained practice output replacement

This extends the existing [gapless practice](../kernel/REQ__gapless-practice.md)
and output transaction for original-coordinate Target playback. The full
native/web BMS player requirements remain active.

## Observable behavior

After actual pause adoption, native boundary presentation and committed input
cutoff, retained Target sessions can apply supported device, rate, channel/
matrix, encoding, period and buffer changes through existing Output controls.
Linux solo/local consumers share the portable service. Unsupported requests
report a concrete reason; cold refusal precedes retirement whenever possible.
No silent device or format substitution is allowed.

Preserve the original Mixer, PCM bank, command producer, retained program,
Runtime, selected policy/speed, source/phase history, recording and acquired
input ownership. An output epoch change does not create a new practice attempt
or reset position, generation, iteration, section or end intent. Resume, loop
and scrub continue through the original common logic.

## Exact clocks and atomic publication

New native stream frame0 does not reset accumulated exact TargetTime. Preserve
the recovered converter's fractional start and both exact coordinate
watermarks across rates; do not recreate them from rounded nanoseconds or new
integer frames. Coordinate replacement uses a separate opaque preparation;
scalar epoch guards remain intact.

Bind the prior authority, original physical/coordinate descriptors, native
record, retained Mixer basis, pause and merger. Require a newer epoch,
compatible coordinate kind and original physical origin, unchanged HOST/
logical domains, exact new frame-zero stream origin and the prior epoch's
checked mathematical logical projection. Projection grants no scalar mapping
or native-evidence permission.

Two original native coordinates must progress in exact units and HOST time,
match actual basis/native metadata, remain fresh/not future and not regress
accepted input/presentation frontiers. Equal rounded nanoseconds do not erase
exact unit progress. Original source/converted reports, submission facts and
held generation must agree; lookahead or replaying an old held suffix alone
does not qualify new native playback.

Preserve the pinned original Mixer creation basis with explicit association
to the complete unique recovered owner. Its source frame-zero point need not
equal the new Target frame-zero point. Old prepared control/practice tokens
become stale. Changed state/pin/input or failed capability validation prevents
publication.

The pin is captured at original setup. Mixer.output_frame_basis() describes
its next physical frame and advances with rendering; it cannot reconstruct the
original creation pin. Recovered-owner association checks immutable source
configuration/initial history and a nonregressed cursor against the retained
pin rather than substituting the current next-frame basis.

Synchronous commit publishes native authority/history, pause binding, raw
native configuration, current output and prevalidated applied capability.
Retain acquired/closed/input HOST prefixes, operation, presentation and both
exact coordinate watermarks; do not rebuild Runtime, transport or capture.

Bind preparation to the merger's exact semantic state even when its queue is
empty: source identities/last chronology, admission ordinal, committed frontier,
configuration and pending/storage counts. Admit then pop is still a state
change. Cold preparation may copy bounded source metadata with checked
allocation; it copies no event payload. Validation/commit and existing input
acquisition/callback operations add no allocation or new mutation counter.

## Pause, input and failure ownership

Coordinate rebind preserves acknowledged Paused, original source identity/
rate/origin, frozen playback frame, startup adoption, source gap, paused-at
duration, exact Target pause gap, source pull monotonicity and HOST floor.
Old native brackets/references cannot certify a new epoch. Held qualification
uses original Target units crossing the exact generation floor.

Compatible pending held PCM retains its complete suffix and interpretation.
Incompatible interpretation changes with nonempty pending output refuse cold.
Recovery transfers the whole converter/Mixer state, never only the Mixer.

The sole native converted worker decides conditional retirement against its
actual pending state before generating or submitting another block. Reading an
empty pending snapshot on another thread does not authorize retirement. The
cold caller selects whether an identical format/matrix may retain a held
suffix or a changed interpretation requires an empty suffix. A refusal leaves
the same live output and epoch in place; no creation identity is consumed.
Cancellation cannot restore an output after retirement authorization wins.
Authorized termination uses the existing native drop/join and complete-owner
recovery. The bounded native control slot adds no callback allocation or lock.

Opaque tickets retain the original native allocation weakly and use checked
nonces; another stream or a later request cannot accept an old ticket. Busy and
unconsumed responses cannot be overwritten. Matching cancellation and worker
authorization share one atomic decision. Authorization forbids another render
or write, while native drop/join and owner recovery may still be pending.
The refusal itself never discards or reinterprets PCM; subsequent ordinary
admission may advance that original suffix. A conditional wait retains the
live clock until actual authorization, distinct from an already retired output.

Both common pumps collect/drain original paused physical key levels and poll
replacement even while old output is suspended. HOST orders bookkeeping and
never substitutes for audio progress. Pending replacement/practice transition
cannot race; resume remains fenced until publication and later actual native
resume adoption/crossing.

Retained paths use NativeEnd=None and PracticePlayback.end_intent for natural/
section completion. Unsupported non-None coordinate NativeEnd refuses before
retirement; existing scalar finite semantics stay intact.

Cold refusal leaves current output/program/accepted capability untouched.
After retirement, open/start/observation/publication failure retains the
existing technical-stop policy plus unique recovered software owner or pending
retirement hold for explicit cleanup/controller retry. Recovered software
is not a running stream. No fake current output or automatic clock continuation.

Stage actual applied capability before authoritative commit. Deliver the
accepted result once for its typed request ID; WouldBlock retries the same
result without rerunning the native transaction. Keep original failure and
cleanup state; destruction occurs outside callbacks.

## Verification

Independent rational, original native snapshot, pause, transaction and request
fixtures cover successful changes, stale/wrong/future/torn evidence, held
suffixes, ownership recovery and capability consistency. Connected portable
solo and multi-member fixtures traverse pause→change→resume→loop/scrub/end intent
and decode original capture to verify identity/conservation. These are software
evidence rather than physical native timing.

Actual desktop acceptance acknowledges a retained pause, edits/applies Output,
checks applied capability and resumes the same play/capture. It requires native
input and clock-capable audio devices. Missing devices produce BLOCKED_ENV;
ALSA null, simulated ports, type checks or static screenshots do not prove
native crossing.

## Known ceiling and full player scope

Known ceiling: Actual input/audio and acoustic verification needs an eligible
host; the current environment has no /dev/input, /dev/uinput or /dev/snd.

Direct-source retained replacement, foreign OS/device/backend combinations,
browser pause/resume and full gapless parity remain full Goal requirements.
This Target dependency does not prove those routes or the full WBS complete.
